# 実験工房｜3Dと観察の使い方

`start_windows.bat` または `python start_local.py` で起動し、[実験工房](http://127.0.0.1:8001/hybrid-lab.html) を開きます。工房で動かした条件は、先生画面の工房からそのまま教材の下書きにできます。

再生・コマ送り・視点の切替は実験の上にあります。3Dの視点は、ドラッグで回し、ホイールやピンチで拡大・縮小できます。注目する値は、一往復や着地など測定できる時点になってから表示します。

| 分野 | 実験 | 最初に見比べること |
|---|---|---|
| 宇宙 | 3D太陽系 | 8惑星の軌道。太陽の質量を変えたときの地球の公転周期。全体、真上、地球と月、土星、彗星へ視点を切り替える |
| 宇宙 | 地球から脱出できる？ | 同じ高度から速さだけを変え、6時間後と10日後の軌道を重ねる。短い観察とエネルギーからの推論を区別する |
| 力学 | 投射と自由落下 | 発射角だけを変え、飛んだ距離と着地点を比べる |
| 力学 | 振り子 | 支点からひもの長さを変え、一往復にかかる時間を測る |
| 力学 | 二重振り子 | 下側の初期角度を1度だけ変え、2つのおもりの軌跡と8秒後の角度を比べる |
| 力学 | ドミノと衝突 | 板の間隔を変え、衝突が次に届く時刻と倒れた枚数を比べる |
| 電気 | 直流回路 | 電源と抵抗の値をそろえて、直列と並列の電流を比べる |
| 波・光・音 | ドップラー効果 | 動く音源の前後で波面の間隔を見て、観測者の聞く高さを聴き比べる |
| 波・光・音 | 凸レンズ | 物体までの距離を変えて、レンズを通る光と像ができる位置を追う |
| 波・光・音 | 音と空気のふるえ | 振動数を変え、音の高さと、空気が密になった場所の間隔を比べる |
| 流体 | 浮力 | 液体をそろえ、物体の密度を変えたときに浮力・重力・水に入った割合がどう変わるか見る |

**「おすすめの2条件を比べる」** から、A/Bを同じ時計で動かせます。自分で条件を決めるときは **「現在の条件をAに保存」→ 値を一つ変える →「現在の条件Bと比べる」**。比較には条件と測定値の表が付き、値がまだ測れないときは「未測定」と表示します。

## 元の3Dを開く

太陽系・投射・ドミノで **「原版3Dを開く ↗」** を押すと、Word原案から復元した場面を開けます。星空・土星の環・月・彗星・天体追従、球の投射と自由落下、ドミノ・タワーと球の衝突の描画と操作を引き継いでいます。起動済みのブラウザでは事前保存後にオフラインでも開けます。

- `docs/original/teacherrelay-physics-original.html`：Word原案から取り出したHTMLの原文。オリジナルの外部ライブラリの指定もそのままです。
- `public/original-3d.html`：工房から使う復元版。同梱のThree.jsと接触計算に差し替え、外部CDNを使わずに起動します。衝突の細かな動きは原版と異なることがあります。

授業用の太陽系では万有引力で8惑星の運動を計算します。月・彗星・小惑星帯は模式表示で、惑星のサイズや遠方の距離も見やすく調整しています。原版の宇宙速度演示は概念をつかむための表示です。速さを数値で比較するときは工房の「地球から脱出できる？」を使います。

音とドップラーのボタンは、条件に対応する音を合成して再生します。生徒の予想や説明は文字で入力します。WebGLが使えない環境では、授業用の実験を簡易3Dまたは2Dで試せます。
